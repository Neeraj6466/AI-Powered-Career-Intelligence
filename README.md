# 🤖 AI-Powered Career Intelligence Platform

An AI-powered career guidance platform that helps students and job seekers analyze their resumes, identify skills, discover suitable career paths, find relevant learning resources, and improve their employability.

---

## 📌 Project Overview

The AI-Powered Career Intelligence Platform is designed to provide personalized career assistance using Artificial Intelligence.

The platform allows users to:

- Register and create an account
- Upload and analyze resumes
- Extract technical skills
- Calculate ATS scores
- Identify missing skills
- Get career recommendations
- Get salary predictions
- Find suitable job opportunities
- Explore recommended courses
- Receive AI-powered career guidance
- Interact with an AI career chatbot

The platform also provides an **Admin Intelligence Control Center** for managing users, jobs, courses, announcements, resumes, feedback, analytics, activity logs, and system/API information.

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze resumes using AI techniques.
2. Identify technical and professional skills.
3. Calculate resume/ATS compatibility scores.
4. Recommend suitable career paths.
5. Identify missing skills.
6. Provide personalized learning recommendations.
7. Help users discover relevant job opportunities.
8. Provide AI-powered career assistance.
9. Provide administrators with platform monitoring and management tools.
